// <os_obrotu> to: right - wokol osi X
//                 forward - wokol osi Z
//                 up - wokol osi Y
// <warunek> to: enable - wlaczony silnik, predkosc to mnoznik (stopnie/sek)
//               rpm    - predkosc zalezy od obrotow silnika * mnoznik (w stpniach)
//               speed  - predkosc to predkosc pojazdu (kph) * mnoznik (w stpniach)
//               turn   - ustala sie kat: wspolczynnik obrotu kierownicy * mnoznik (w stpniach)
//               gas    - ustala sie kat: wcianiety gaz (maks wcisniety to 1) * mnoznik (w stpniach)
//               brake  - ustala sie kat: wcianiety hamulec (maks wcisniety to 1) * mnoznik (w stpniach)
//               direction - ustala sie kat: (jazda przod to 1, jazda tyl to 0) * mnoznik (w stpniach)
//               clutch - ustala sie kat: (wysprzeglony to 1, sprzeglo puszczone to 0) * mnoznik (w stpniach)

//                          add_rot_forward dodaje staly obrot wokol osi Z
//                          add_rot_up dodaje staly obrot wokol osi Y
// <dodatkowy_skret_rotacja> to stala wartosc (w stopniach) dodatkowego obrotu
//
// dodatkowe (stale) skrety mozna stosowac wiecej niz jeden, na przyklad na koncu linijki moze byc add_rot_right 15 add_rot_up 45 (w dowolnej kolejnosci), a moze nie byc zadnego
